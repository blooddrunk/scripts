# Raksmart VPS 自动下单助手

一个 Tampermonkey 脚本，用于 Raksmart（billing.raksmart.com）特价 VPS
的定时抢购：自动勾选「内网」与「服务条款」，按配置的场次和期望价格
校验通过后自动点击「立即购买」。

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展
2. Tampermonkey → 管理面板 → 「+」新建脚本，粘贴
   `raksmart-auto-order.user.js` 全部内容并保存（Ctrl+S）
3. 打开目标商品的订购页（`https://billing.raksmart.com/ec/price?...`），
   首次运行会写入默认设置，右下角出现状态面板
4. 点击右下角「设置」（或 Tampermonkey 菜单「打开自动下单设置」），
   核对期望价格、付款周期与抢购场次后保存——保存会刷新页面生效

## 功能

| 功能 | 说明 |
|---|---|
| 自动勾选 | 自动勾选「内网」复选框与「我已阅读并同意服务条款」（500ms 限频防抖，暂停时仍保持勾选） |
| 商品校验 | URL 的 `pid` / `sample_id` / `activity_id` 需与配置一致才动作，防止串页面误购（留空即不限制） |
| 场次模式 | **单次**：带时区的 ISO 8601 起止时间；**每日循环**：`HH:mm` 起止 + 固定 UTC 偏移（默认 UTC+8），不受电脑时区影响，结束时间早于开始按跨天处理 |
| 价格校验 | 期望价格（±0.001）与付款周期（如「每年」）都匹配才点击购买；报价需连续稳定 800ms 才动手，避开加载途中的临时价格 |
| 开抢前预热 | 默认开抢前 60 分钟进入预热：页面长时间不完整、检测到缺货/加载失败时自动刷新，保证开抢瞬间页面是活的（刷新带 200–500ms 随机抖动） |
| 防重复下单锁 | 以「商品三参数 + 场次开始时间」为键记录点击；一旦点击过立即购买，本场不再重复点击，防止重复创建订单。可在面板或菜单中手动重置（带确认弹窗） |
| 无锁重试模式 | 关闭下单锁后改为按固定间隔（默认 5 秒）重试点击，适合自己盯着页面时使用 |
| 状态面板 | 右下角 Shadow DOM 面板：当前价/期望价/场次/倒计时实时显示，暂停、设置、重置锁按钮 |
| 设置持久化 | 设置存 GM 存储（回退 localStorage），更新脚本不丢配置；首次运行写入默认值，Tampermonkey 菜单可一键恢复默认（保留下单锁） |

## 默认配置

脚本自带一份针对「$49.90/年」活动商品的默认配置（内置于
`DEFAULT_CONFIG`），首次运行自动写入。**请务必在设置面板中核对自己的
商品参数与场次**，默认值仅作参考：

- 商品：`pid=1889`、`sample_id=psam_01M24N3CFJDQ6AX41HVYFT5GCF`、
  `activity_id=act_01M4TBMTG2VMWJPXXCYX2WZS2S`
- 期望价格 `$49.90` / 周期「每年」
- 每日场次 `20:00–20:10`（UTC+8）

## 工作方式

主循环每 250ms 运行一次（另有 MutationObserver 监听 DOM 变化、
页面聚焦/可见性变化时即时触发），每轮依次：

1. 校验 URL 商品参数与配置一致，不一致则停止一切自动操作
2. 自动勾选内网与服务条款
3. 计算当前所处时段：场次外 / 预热期 / 抢购中，面板显示对应状态与倒计时
4. 预热期与抢购中检测页面健康度（表单是否齐全、是否缺货/报错），
   异常超过阈值（正常 12s、报错 3s）自动刷新
5. 抢购中等待表单与报价就绪 → 报价签名（价格|周期|勾选状态）稳定
   800ms → 校验周期与价格 → 点击「立即购买」并落下单锁

时钟偏移校准（`clockOffsetMs`）不在设置表单中，需要时可直接修改
GM 存储中 `raksmart-auto-order:settings` 的该字段（毫秒，正数为调快）。

## 已知限制（诚实声明）

- 只操作前端页面。点击购买后的库存确认、下单成败、支付流程均由
  服务端决定，脚本无法保证抢到，也无法代付。
- 页面元素定位依赖 Raksmart 前端的 class 名（如
  `.price-order-summary-price-value`、`.price-order-btn-buy`），
  对方改版后选择器可能失效，需要更新脚本。
- 下单锁是「点击前检查、点击后落锁」，同一商品同一场次在多个标签页
  同时开时存在竞态，可能都通过检查而重复点击；抢购时只保留一个标签页。
- 每日场次使用固定 UTC 偏移；若 Raksmart 活动按其他时区滚动开场，
  需自行换算偏移分钟数。
- 自动刷新在浏览器离线（`navigator.onLine === false`）时会暂停等待。

## 使用须知

仅供个人为自己的订单自动化重复性操作。使用本脚本产生的任何账号
风控、订单纠纷或损失由使用者自行承担；请知悉并遵守目标网站的
